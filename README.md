Entry for [One Line to Get Your Agent Deleted](https://make.fun/bounty/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0) on [make.fun](https://make.fun).

`main.py` (Python 3, stdlib only) writes a single original dark one-liner to
`/output/entry.txt` — the one line an AI agent would never dare say out loud.

## Run

```sh
python3 main.py
```

The output path resolves as: `ENTRY_OUT` (file or directory) →
`MAKEFUN_OUTPUT_DIR` (directory) → `/output/entry.txt` → `./entry.txt`.
